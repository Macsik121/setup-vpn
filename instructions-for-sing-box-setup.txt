## adding vless
Вот универсальный шаблон для добавления любых подобных VLESS Reality ключей в секцию outbounds вашего config.json. Из него убраны все специфические значения, чтобы вы могли просто копировать этот блок для каждого нового сервера и вставлять данные из ссылки.

📋 Универсальный JSON-шаблон для VLESS Reality

json
{
  "type": "vless",
  "tag": "УНИКАЛЬНЫЙ_ТЕГ_УЗЛА",
  "server": "IP_АДРЕС_ИЛИ_ДОМЕН",
  "server_port": 443,
  "uuid": "ВАШ_UUID",
  "flow": "xtls-rprx-vision",
  "network": "tcp",
  "domain_resolver": "dns-remote",
  "tls": {
    "enabled": true,
    "server_name": "МАСКИРОВОЧНЫЙ_SNI_ДОМЕН",
    "utls": {
      "enabled": true,
      "fingerprint": "edge"
    },
    "reality": {
      "enabled": true,
      "public_key": "ПУБЛИЧНЫЙ_КЛЮЧ_PBK",
      "short_id": "SHORT_ID_СЕССИИ"
    }
  }
}
Используйте код с осторожностью.

🗺️ Памятка: куда вставлять значения из ссылки vless://

Чтобы быстро заполнить этот шаблон, ориентируйтесь на структуру вашей ссылки:

vless://  UUID  @  SERVER  :  PORT  ?encryption=none&flow=  FLOW  &type=  NETWORK  &headerType=none&security=reality&fp=  FINGERPRINT  &pbk=  PUBLIC_KEY  &sid=  SHORT_ID  &sni=  SERVER_NAME  #  TAG

• tag — название узла (пишется латиницей без пробелов, например "proxy", "japan-backup", "node-3"). Берется из текста после знака #.
• server — IP-адрес или домен сервера. Находится в ссылке между знаком @ и двоеточием : (в вашем примере: 66.90.92.53).
• server_port — цифры порта сразу после двоеточия (в вашем примере: 443). В JSON пишется без кавычек.
• uuid — длинный уникальный идентификатор. Идет в самом начале ссылки сразу после vless:// и до знака @.
• flow — технология шифрования внутри TLS. Ищется после параметра flow= (в вашем примере: xtls-rprx-vision).
• network — тип сети (обычно tcp). Ищется после параметра type=.
• server_name — домен маскировки. Ищется после параметра sni= (в вашем примере: 919c2e654b58.j.cloudfront.hls.ttvnw.net).
• public_key — публичный Reality-ключ. Ищется после параметра pbk=.
• short_id — короткий ID сессии Reality. Ищется после параметра sid=.

💡 Как объединить несколько узлов в массиве outbounds

Каждый новый узел — это отдельный объект внутри фигурных скобок {...}, и они должны разделяться запятыми. Последний элемент в списке запятой не закрывается.

### install a fresh browser if the system is old

Установка современных версий браузеров (включая Firefox) на CentOS 7 штатными средствами (через yum) давно невозможна, так как операционная система официально признана устаревшей, а версии библиотек в ней застыли на уровне 2014 года.
Использование Flatpak — это единственный надежный способ запустить самый свежий и безопасный Firefox на CentOS 7, так как Flatpak изолирует приложение и несет все новые библиотеки с собой.
Ниже приведена пошаговая инструкция по настройке.

Шаг 1. Установка и настройка Flatpak в системе

В репозиториях CentOS 7 уже есть пакет Flatpak, но перед его установкой рекомендуется обновить кэш пакетного менеджера.
Выполните в терминале:
bash
# 1. Обновляем информацию о пакетах
sudo yum update -y

# 2. Устанавливаем сам Flatpak
sudo yum install flatpak -y
Используйте код с осторожностью.

Шаг 2. Подключение официального репозитория Flathub

Flathub — это главный мировой репозиторий, откуда скачиваются почти все Flatpak-приложения, включая Firefox. Добавим его в систему:
bash
sudo flatpak remote-add --if-not-exists flathub https://flathub.org
Используйте код с осторожностью.

Шаг 3. Перезагрузка системы (Обязательно)

Для того чтобы среда рабочего стола (GNOME/KDE) корректно увидела новые пути Flatpak и ярлыки приложений, необходимо перезагрузить компьютер:
bash
sudo reboot
Используйте код с осторожностью.

Шаг 4. Установка Firefox

После перезагрузки откройте терминал и запустите установку Firefox из репозитория Flathub. Система автоматически скачает сам браузер и необходимые для него изолированные библиотеки (Runtime):
bash
sudo flatpak install flathub net.waterfox.waterfox -y
Используйте код с осторожностью.
Процесс может занять несколько минут, так как в первый раз Flatpak будет скачивать весомые базовые графические платформы (Gnome/Freedesktop Runtime).

Шаг 5. Запуск Firefox

После успешного завершения установки запустить Firefox можно двумя способами:
1. Через графический интерфейс: Иконка Firefox автоматически появится в вашем меню приложений (в категории «Интернет» или «Офис»).
2. Через терминал: Если вам нужно запустить браузер вручную из консоли, выполните:bash
flatpak run net.waterfox.waterfox
Используйте код с осторожностью.

💡 Полезные команды для работы с Flatpak:

• Обновление Firefox (рекомендуется делать раз в неделю, чтобы браузер оставался безопасным):bash
flatpak update net.waterfox.waterfox -y

• Просмотр установленных приложений:bash
flatpak list
Используйте код с осторожностью.
